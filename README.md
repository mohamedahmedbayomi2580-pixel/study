# study.ai

مساعد ذكي للطلاب: ارفع مادتك (PDF / DOCX / TXT) واحصل على ملخصات، شرح، أسئلة، بطاقات، خريطة ذهنية، خطة مذاكرة، ومحادثة مع المادة.
تطوير وإنشاء: **محمد أحمد** – طالب حاسبات وذكاء اصطناعي – بنها.

## الهيكل
- `client/`  تطبيق React + TypeScript + Tailwind (Neumorphism، RTL/LTR، وضع ليلي). يُبنى كـ **Windows EXE** (Electron) و**Android APK** (Capacitor). المحادثات والمواد تُخزَّن محليًا: **SQLite على الهاتف**.
- `server/`  سيرفر Node.js: رفع واستخراج النص، محرك Multi-AI (OpenAI / Gemini / Claude / أي مزود متوافق مع OpenAI)، تشغيل متوازي + إعادة محاولة + مراجعة ودمج + حساب التكلفة. **مفاتيح API تبقى في السيرفر فقط.**
- `.github/workflows/` بناء الـ EXE والـ APK تلقائيًا.

## 1) كيف يعمل الذكاء الاصطناعي (Google Gemini فقط، بدون مفاتيح عند الطالب)
- الطالب يفتح التطبيق ← يوافق على استخدام Google AI ← يستخدم مباشرة. لا يرى ولا يدخل أي مفتاح.
- كل رسالة وبطاقة وخريطة ذهنية تُرسل إلى **وسيط مجاني (Cloudflare Worker)** يحمل مفتاح Google مخفيًا ثم يمرّرها إلى Gemini.
- المفتاح موجود عندك أنت فقط كـ Secret في الـ Worker (لا يوجد داخل الـ APK/EXE).
- الحد المجاني من Google **مشترك بين كل الطلاب**. لا تفعّل الفوترة (Billing) على مشروع Google الخاص بالمفتاح حتى لا يصل إليك أي تحصيل أبدًا.

### نشر الوسيط (مرة واحدة)
1. أنشئ مفتاحًا مجانيًا من https://aistudio.google.com/apikey
2. افتح https://dash.cloudflare.com ← Workers & Pages ← Create ← Hello World ← Deploy ← Edit code، والصق محتوى `worker/index.js` ← Deploy.
3. من الـ Worker: Settings ← Variables and Secrets ← أضف Secret باسم `GEMINI_API_KEY` وقيمته مفتاحك (واختياريًا `GEMINI_MODEL`).
4. انسخ رابط الـ Worker (مثل `https://study-ai-proxy.xxxx.workers.dev`).
5. في GitHub: Settings ← Secrets and variables ← Actions ← تبويب **Variables** ← New variable باسم `AI_PROXY_URL` وقيمته رابط الـ Worker. ثم أعد تشغيل Actions ليدخل الرابط داخل التطبيق.

(للتجربة السريعة بدون إعادة بناء: التطبيق ← الإعدادات ← إعدادات متقدمة ← الصق رابط الـ Worker.)

> مجلد `server/` القديم لم يعد مطلوبًا.

## 2) تشغيل الواجهة للتجربة
```bash
cd client
npm install
npm run dev
```

## 3) بناء EXE و APK على GitHub
1. أنشئ مستودعًا جديدًا على GitHub وارفع **كل محتويات هذا المجلد** (بما فيها المجلد المخفي `.github`).
2. ادخل تبويب **Actions** وشغّل `Build Windows EXE` و`Build Android APK` (أو ستعمل تلقائيًا عند كل push على `main`).
3. بعد اكتمال التشغيل افتح الـ run ← **Artifacts** ← حمّل:
   - `study-ai-windows-exe` ← ملف `study-ai-setup-0.1.0.exe` (Windows 10 x64)
   - `study-ai-android-apk` ← ملف `app-debug.apk` (ثبّته على الهاتف، فعّل "التثبيت من مصادر غير معروفة")
4. افتح التطبيق ← وافق على استخدام Google AI ← ابدأ.

> الـ APK الناتج نسخة Debug صالحة للتثبيت والتجربة. للنشر على Google Play تحتاج توقيع Release (keystore).

## الحالة الحالية (المرحلة 1)
تعمل: الواجهة كاملة، رسالة الترحيب عند أول تشغيل، تخزين محلي (SQLite على الأندرويد)، رفع PDF/DOCX/TXT/رابط صفحة، ملخص/شرح/اختبار تفاعلي/بطاقات مع إعادة الصعبة/خريطة ذهنية (مخطط نصي)/خطة مذاكرة، محادثة مع المادة (RAG بسيط)، مفضلة، سجل نشاط، بحث في المواد، محرك Multi-AI مع حالة كل نموذج والتكلفة.

لم تُنفّذ بعد (المراحل القادمة): حسابات وGoogle login وفواتير واشتراكات، لوحة الإدارة، PostgreSQL + pgvector + Redis/BullMQ، Cloudflare R2، OCR للصور والمسح الضوئي، تفريغ الصوت، فيديوهات YouTube، تصدير PDF عربي، خريطة ذهنية مرسومة، بودكاست/PowerPoint/صوت، مشاركة الملخصات، تقدّم دراسي وتذكيرات.

## ما أُضيف في هذه النسخة
- **اطلب ما تريد:** اكتب طلبك بحرية ← يعرض التطبيق خطة (فهم الطلب، المصادر، الأدوات، هل يحتاج بحث، نصائح بأسلوب دكتور جامعي) ← تعدّلها ← «ابدأ التنفيذ». لا يُرسل محتوى أي ملف قبل الضغط على الزر.
- **المحادثة:** رد يظهر كلمة كلمة (بث مباشر)، زر إيقاف، «إجابة أخرى»، بحث Google مع المصادر، تثبيت المحادثات، بحث في المحادثات، نسخ المحادثة.
- **الشرح:** باللهجة المصرية / الفصحى / مبسّط.
- **المتصفح والمواقع:** يفتح ChatGPT / Gemini / Claude / AI Studio في متصفح جهازك بإذنك وينسخ طلبك، وأنت تسجّل الدخول وتلصق وترجع تحفظ الرد. لا قراءة تلقائية لصفحات المواقع.
- الوضع الداكن هو الافتراضي.
- **بعد تحديث الـ Worker:** انسخ `worker/index.js` الجديد إلى Cloudflare وانشره من جديد (Deploy).

## Study AI Engine (المحرك المركزي) — `client/src/ai.ts`
```
طلب المستخدم
   ↓
Planner: يفهم الطلب ويعرض خطة (الأدوات + النموذج لكل أداة + بحث؟ + مراجعة؟)
   ↓  (المستخدم يعدّل ثم يضغط «ابدأ التنفيذ»)
Orchestrator: يشغّل المهام بالتوازي، ويختار النموذج لكل مهمة، وبديل تلقائي لو فشل نموذج
   ↓
Providers:  Gemini (مجاني) · ChatGPT (اختياري) · Claude (اختياري)
   ↓
مراجعة اختيارية بنموذج ثانٍ ← النتيجة: شرح · بحث · ملخص · امتحان · بطاقات · خريطة · درس مرئي صوتي
```
- Gemini يعمل بمفتاح مجاني (الإعدادات) أو عبر الوسيط. ChatGPT وClaude يظهران كخيارات فور إضافة مفتاح لكل منهما، وكلاهما API مدفوع.
- **الشرح المرئي بالصوت:** شرائح يقرؤها صوت الجهاز (Web Speech). ليس فيديو مولّدًا ولا يُصدَّر MP4.
- **المتصفح والمواقع:** تسليم يدوي (فتح الموقع + نسخ الطلب) ثم استيراد الرد إلى محادثة أو ملاحظة. لا قراءة تلقائية لصفحات المواقع.

## المصادر المدعومة الآن
PDF · DOCX · **PPTX** · TXT · **صور (JPG/PNG/WEBP)** · **صوت (MP3/WAV/AAC/OGG/FLAC، حتى 12MB)** · صفحات ويب · **روابط YouTube**.
- الصور والصوت ويوتيوب يُستخرج نصها عبر Gemini الرسمي (تُرسل إلى Google بموافقتك)، وتحتاج مفتاح Gemini أو الوسيط. استخراج يوتيوب ميزة تجريبية عند Google وقد لا تعمل مع كل الفيديوهات.
- لو تستخدم الوسيط: انسخ `worker/index.js` الجديد وانشره (Deploy) ليدعم الصور والصوت.

## تنفيذ الطلبات
- سجل خطوات التنفيذ (أي نموذج، متى بدأ وانتهى، التحويل التلقائي عند الفشل، المراجعة).
- زر «أعد المحاولة للمهام الفاشلة».
- استهلاك كل نموذج بالتوكنات في الإعدادات.

> مجلد `server/` قديم ولا تستخدمه الواجهة؛ المحرك الفعلي (Gemini + ChatGPT + Claude) في `client/src/ai.ts`.
